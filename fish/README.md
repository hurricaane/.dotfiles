# fish

Configuration of the [fish shell](https://fishshell.com), my login shell. Linked to `~/.config/fish`.

It sets up **vi key bindings**, a lot of **abbreviations** (git, tmux, kubectl…), the integrations of the other terminal tools (Starship, atuin, zoxide, Television…), and **attaches to tmux** when a terminal opens.

## Requirements

- fish 4.x
- Called from `config.fish`, which errors without them: `atuin`, `fzf`, `zoxide`, `direnv`, `bat-extras` (`batman`, `batpipe`, `batdiff`), `tv` (Television), `starship`
- Used by aliases and abbreviations: `eza`, `bat`, `wl-clipboard`, `nvim`, `tmux`, `sesh`, `lazygit`, `yazi`, `thefuck`
- A [Nerd Font](https://www.nerdfonts.com/) for the icons

## Installation

```sh
ln -s ~/dotfiles/fish ~/.config/fish   # or `just link`
chsh -s /usr/bin/fish
fisher update                          # installs the plugins from fish_plugins
```

If fisher isn't installed yet: `curl -sL https://raw.githubusercontent.com/jorgebucaran/fisher/main/functions/fisher.fish | source && fisher update`.

## Structure

```text
fish/
├── config.fish            # Environment, PATH, tool integrations, prompt, vi mode, tmux auto-start
├── fish_plugins           # Plugins managed by fisher
├── fish_variables         # Universal variables (written by fish itself)
├── conf.d/
│   ├── abbrs.fish         # Abbreviations
│   ├── aliases.fish       # Aliases
│   ├── atuin.env.fish  turso*.fish                # PATH snippets added by installers
│   └── zoxide.fish                                # Plugin files (fisher)
├── functions/             # Autoloaded functions (mine + plugin ones)
├── completions/           # Completions (generated by tools or plugins)
└── themes/                # Catppuccin and Tokyo Night themes
```

Files in `conf.d/` are sourced before `config.fish`, in alphabetical order. Plugin files (`zoxide.fish`, `fisher.fish`, the `catppuccin-*` themes) are written by fisher: don't edit them by hand.

## config.fish

### Environment

Set as universal exported variables, so they are also available outside interactive shells:

| Variable          | Value                                                |
| ----------------- | ---------------------------------------------------- |
| `EDITOR`          | `nvim`                                               |
| `SUDO_EDITOR`     | `nvim`                                               |
| `VISUAL`          | `~/.local/share/bob/nvim-bin/nvim` (the bob nightly) |
| `STARSHIP_CONFIG` | `~/.config/starship/starship.toml`                   |
| `BAT_THEME`       | `Catppuccin Mocha`                                   |
| `ZK_NOTEBOOK_DIR` | `~/Documents/Notes`                                  |

The greeting is turned off. In interactive shells, `PATH` gets `~/.local/bin`, bob's Neovim, Go, Cargo and Nix, plus Homebrew when it is installed (Linuxbrew or `/opt/homebrew`).

### Tool integrations

| Tool       | What it adds                                                                                            |
| ---------- | ------------------------------------------------------------------------------------------------------- |
| atuin      | Shell history database. Its default bindings are off (`ATUIN_NOBIND`), see [Key bindings]               |
| fzf        | `fzf --fish` key bindings                                                                               |
| zoxide     | Replaces `cd` (`zoxide init fish --cmd cd`)                                                             |
| direnv     | Loads `.envrc` files, evaluated on each prompt (`direnv_fish_mode eval_on_arrow`)                       |
| bat-extras | `batman` as `MANPAGER`, `batpipe` as `LESSOPEN` (colored `less`)                                        |
| Television | Shell integration: `Ctrl-t` smart autocomplete, channel picked from the command line (see [television]) |
| mise       | Activated by the system (`/usr/share/fish/vendor_conf.d`), not by this config                           |

[Key bindings]: #key-bindings
[television]: ../television/README.md#shell-integration

### Prompt

[Starship](../starship/README.md) with a **transient prompt**: once a command runs, its prompt collapses to the `❯` character, so the scrollback stays compact.

### tmux auto-start

When a terminal opens (outside tmux and outside SSH):

- if tmux sessions exist, it **attaches to the first one** (`exec tmux attach`);
- otherwise it opens the **sesh picker** (`tv sesh`) to choose or create a session.

## Key bindings

Vi mode (`fish_vi_key_bindings`), on top of the default emacs bindings in insert mode (`Ctrl-a`, `Ctrl-e`, `Ctrl-w`… still work). The cursor is a line in insert mode and a block in normal mode.

| Keys     | Mode   | Action                                     |
| -------- | ------ | ------------------------------------------ |
| `jk`     | insert | Normal mode (replaces `Esc`)               |
| `Ctrl-s` | insert | Accept the next word of the autosuggestion |
| `Ctrl-r` | insert | atuin history search                       |
| `/`      | normal | atuin history search                       |
| `Ctrl-t` | insert | Television smart autocomplete              |

## Abbreviations

Abbreviations expand when you press space, so the full command lands in the history. Defined in `conf.d/abbrs.fish`.

| Abbr                  | Expands to                                                     |
| --------------------- | -------------------------------------------------------------- |
| `v`, `nv`             | `nvim`                                                         |
| `vc`, `nvc`           | `nvim` with the Snacks file picker open                        |
| `s`                   | `sesh-sessions` (session picker)                               |
| `ta` `tl` `tk`        | `tmux attach` / `tmux ls` / `tmux kill-server`                 |
| `ef`                  | `exec fish`                                                    |
| `wm`                  | `workmux`                                                      |
| `dots`                | `just -f ~/dotfiles/justfile` (dotfiles recipes from anywhere) |
| `lg`                  | `lazygit`                                                      |
| `cx`                  | `chmod +x`                                                     |
| `cl`                  | `clear -x`                                                     |
| `tt`                  | `taskwarrior-tui`                                              |
| `tfr` / `tfu`         | `terraform` / `tofu`                                           |
| `k` `kx` `kns` `kget` | `kubectl` / `kubectx` / `kubens` / `kubectl get`               |
| `zk*`                 | zk note-taking commands (`zkd` daily, `zkn` new note…)         |

**Git**: the usual oh-my-zsh git plugin set (`gst`, `gaa`, `gc`, `gco`, `gp`, `gpf`, `grbi`, `gsta`…). The ones worth knowing:

| Abbr    | Expands to                                                                                                                             |
| ------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `gcai`  | `git commit -e -m "$(~/dotfiles/scripts/ai-commit-msg.sh)"`: commit with a message written by Claude Haiku, opened in the editor first |
| `gcm`   | Checkout the main branch, whatever its name (`git_main_branch`)                                                                        |
| `grbm`  | Rebase on the main branch                                                                                                              |
| `gpf`   | `git push --force-if-includes --force-with-lease`                                                                                      |
| `gpsup` | Push and set the upstream to `origin/<current branch>`                                                                                 |
| `groh`  | Hard reset to `origin/<current branch>`                                                                                                |
| `glg`   | Colored graph log of all branches                                                                                                      |

## Aliases

| Alias                 | Command                                                                |
| --------------------- | ---------------------------------------------------------------------- |
| `ls`, `l`, `ll`, `la` | `eza` long listings with icons and git status (`la`: hidden files too) |
| `cat`                 | `bat`                                                                  |
| `diff`                | `batdiff`                                                              |
| `copy` / `paste`      | `wl-copy` / `wl-paste`                                                 |
| `nfsh` / `sfsh`       | Edit / reload `config.fish`                                            |
| `git`                 | `git` with `LANG=en_US` (English output whatever the locale)           |

## Functions

| Function            | Description                                                                      |
| ------------------- | -------------------------------------------------------------------------------- |
| `y`                 | Open yazi, and `cd` into the directory you were in when quitting it              |
| `sesh-sessions`     | Pick a sesh session with Television, then connect to it                          |
| `backup <path>`     | Rename a file or folder to `<path>.bk` (refuses to overwrite an existing backup) |
| `restore <path>.bk` | Rename a `.bk` backup back to its original name                                  |
| `help <cmd>`        | Show `<cmd> --help` (or `-h`) highlighted by bat                                 |
| `fuck`              | thefuck: correct the previous command                                            |
| `git_main_branch`   | Print the main branch name (`main`, `master`, `trunk`…), used by `gcm` / `grbm`  |
| `ssh`               | `ssh` with `TERM=xterm-256color`, for hosts that don't know `xterm-ghostty`      |
| `sudo`              | `sudo apt …` runs `nala` instead (Debian/Ubuntu hosts)                           |
| `bw_unlock`         | Unlock the Bitwarden CLI and export `BW_SESSION`                                 |
| `bw_copy <search>`  | Pick a Bitwarden login with fzf and copy its username / password                 |

## Plugins

Managed by [fisher](https://github.com/jorgebucaran/fisher), listed in `fish_plugins`:

- [jorgebucaran/fisher](https://github.com/jorgebucaran/fisher): the plugin manager itself
- [icezyclon/zoxide.fish](https://github.com/icezyclon/zoxide.fish): `z` / `zi` functions and completions
- [catppuccin/fish](https://github.com/catppuccin/fish): Catppuccin themes

## Theme

Catppuccin Mocha (`fish_config theme choose catppuccin-mocha`). The autosuggestion color is brightened (`#9399b2`) so it stays readable on the transparent terminal background.
